# 📱 Awesome iOS Shortcuts

This repository is a curated collection of easy-to-follow guides, step-by-step instructions, and iCloud download links for powerful iOS and Siri Shortcuts. 

Whether you want to streamline your daily routines, automate your smart home, or optimize your mobile workflow, you will find clean blueprints to build them here.
